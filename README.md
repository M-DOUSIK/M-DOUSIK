### Featured Projects

**[Systolic Squad](https://github.com/M-DOUSIK/systolic-squad)** — Depth-Estimation NPU on PolarFire SoC  
16×16 INT8 systolic array · SystemVerilog · RISC-V bare-metal C · INT8 quantisation  
Custom NPU in FPGA fabric running FastDepth and MiDaS monocular depth from a live camera. 6.7× faster than the on-chip CPU, bit-identical to the reference model. **🏆 1st Prize, FPGA Track, IEEE EDS Edge AI Hackathon 2026.**

**[MedSight](https://github.com/M-DOUSIK/MedSight)** — Offline Medication Dispenser on µT-Kernel  
STM32N6 · µT-Kernel 3.0 RTOS · NPU face recognition · Embedded vision  
Recognises the patient by face, dispenses and physically counts pills, and logs adherence locally with no radio. 209 ms face recognition on the NPU, ~90 % CPU idle. TRON Programming Contest 2026.

**[HaDes-V](https://github.com/M-DOUSIK/my_rv32-HaDesV_Challenge)** — Pipelined RISC-V Processor (RV32I)  
5-stage pipeline · Zicsr · Machine-mode traps · FPGA (Basys3 Artix-7) · SystemVerilog  
My implementation of the TU Graz Microcontroller Design Lab processor: all five pipeline stages, the decoder, hazard handling and forwarding, and the complete CSR file with trap/interrupt handling. Full marks (56/56) on TU Graz's official test bench.

**[ParaKey](https://github.com/M-DOUSIK/ParaKey)** — Parallelized Keypad Controller  
Verilog · FSM · Cadence IC Design  
O(R+C) bidirectional scan FSM replacing conventional O(R×C) sequential logic. Characterised in Cadence, area and power trade-off documented.

**[QSSE](https://github.com/M-DOUSIK/Centient)** — Queen Successor Selection Engine  
Cadence Xcelium · Genus · Innovus · RTL-to-GDSII  
RAM-backed sequential accelerator for swarm leader selection in a nano-drone SoC, scaling from 4 to 256 drones with 84% fewer LUTs and 35 fewer DSPs than the combinational first version. Full physical design flow completed.

**[Nodero](https://github.com/M-DOUSIK/Nodero)** — Zero-Trust Sleep Alarm System  
ESP32-S3 · 60 GHz mmWave radar · 6-axis IMU · On-device ML · Cooperative firmware  
Hardware-software system that uses sensor fusion and an on-device ML model (SleepScorer) to verify you are cognitively awake. 9-state cooperative state machine.
